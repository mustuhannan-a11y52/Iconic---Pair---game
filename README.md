# Iconic Pairs — deployment guide

This is a real, standalone build of the game (not the Claude-artifact
version) — it uses Supabase for shared data (game links, pairs library,
leaderboards) instead of Claude's artifact storage, so it works on any host,
including Vercel.

## 1. Create a free Supabase project

1. Go to https://supabase.com and sign up / log in (free tier is enough).
2. Create a new project. Pick any name/region, set a database password
   (you won't need it for this app, just save it somewhere).
3. Once the project is ready, open **SQL Editor** in the left sidebar,
   paste in the contents of `supabase-setup.sql` (included in this project),
   and click **Run**. This creates the one table the app needs.
4. Go to **Project Settings -> API**. You'll need two values from this page:
   - **Project URL**
   - **anon public** key

## 2. Configure environment variables

Copy `.env.example` to `.env.local` and fill in the two values from step 1:

```
VITE_SUPABASE_URL=https://your-project-ref.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-public-key
```

## 3. Run it locally (optional, to test before deploying)

```
npm install
npm run dev
```

Opens at http://localhost:5173. Add `#admin` to the end of the URL to reach
the admin console (e.g. http://localhost:5173/#admin).

## 4. Deploy to Vercel

**Easiest path — via GitHub:**
1. Push this project to a new GitHub repo.
2. Go to https://vercel.com, click **Add New -> Project**, and import that repo.
3. Vercel auto-detects Vite — no build settings to change.
4. Before deploying, add the two environment variables from step 2 under
   **Environment Variables** in the Vercel project settings
   (`VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`).
5. Click **Deploy**.

**Or via CLI, without GitHub:**
```
npm install -g vercel
vercel
```
Follow the prompts. When it asks about environment variables, add the same
two keys (or add them afterward in the Vercel dashboard, then run
`vercel --prod` again).

## Using it once deployed

- Players go to your Vercel URL directly (e.g. `https://your-app.vercel.app`)
  and enter a game code.
- You (admin) go to `https://your-app.vercel.app/#admin` to create links,
  edit the pairs library, change the background, and set card count.
- The link generated by "Create link" in the admin console is the exact URL
  to hand to players.

## What's different from the Claude-artifact version

- Storage is now Supabase instead of Claude's built-in artifact storage —
  functionally identical from the game's point of view.
- Everything else (game logic, visuals, music, scoring, admin console) is
  unchanged.
- Note: since there's no login system, anyone with your site's URL and the
  right game code can read/write that game's data (same trust model as the
  original). Fine for an internal team-building tool; worth knowing if you
  ever expand this beyond that.
